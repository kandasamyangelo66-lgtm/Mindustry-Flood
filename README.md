# Mindustry-Flood
🌊 Mindustry Flood

Welcome to Mindustry Flood!

Mindustry Flood is a custom Mindustry mod featuring infection mechanics, spreading blocks, team interactions, and custom sprites.

✨ Features

- 🔴 Infection mechanics that spread across blocks
- 🔵 Multiple infection colors and teams
- 🟡 Team-based protection and interactions
- 🛡️ Defensive shield blocks
- 📡 Radar defensive block
- 💥 Custom block destruction mechanics
- 🎨 Custom sprites and visuals
